## ⚡ Creator Pipeline

### Overview

The Creator Pipeline is your end-to-end workflow for:
1. Generating content with AI
2. Editing and refining
3. Publishing to social media

### Step-by-Step Workflow

#### Step 1: Choose Content Type

**Image Content:**
- Best for: Social posts, ads, banners
- Flow: AI Generate → Image Designer → Social Post

**Video Content:**
- Best for: Reels, shorts, promo videos
- Flow: AI Generate → Video Editor → Social Campaign

#### Step 2: Generate with AI

**Writing Effective Prompts:**

✅ **Good Prompt:**
```
"A modern minimalist product photo with soft studio lighting, 
white background, professional setup, sharp focus on product, 
blue and purple accent colors"
```

❌ **Poor Prompt:**
```
"nice product picture"
```

**Pro Tips:**
- Be specific about style, mood, and colors
- Mention composition (centered, rule of thirds, etc.)
- Specify lighting (soft, dramatic, natural, etc.)
- Reference art styles if needed (watercolor, minimalist, etc.)

**Generation Time:**
- Average: 20 seconds
- Outputs: 4 variants per generation

#### Step 3: Select & Edit

1. Review all 4 generated variants
2. Select assets you want to use (can select multiple)
3. Click **Edit** to open in Image Designer or Video Editor
4. Refine and customize as needed

#### Step 4: Schedule & Publish

**Option A: Create Social Campaign**
- Schedule posts across multiple platforms
- Set publishing times
- Track performance

**Option B: Save to Media Library**
- Store for later use
- Organize with tags
- Access from any tool

**Shape Properties:**
- Fill color

### Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Undo | Ctrl/Cmd + Z |
| Redo | Ctrl/Cmd + Shift + Z |
| Delete Layer | Delete/Backspace |
| Duplicate | Ctrl/Cmd + D |

### Exporting

#### Export Formats

**PNG:**
- Best for: Graphics with transparency
- Use when: Need transparent backgrounds
- File size: Larger

**JPG:**
- Best for: Photos and complex images
- Use when: Want smallest file size
- File size: Smallest (no transparency)

**WebP:**
- Best for: Modern web graphics
- Use when: Want best compression
- File size: Medium

#### Export Workflow

1. Click **Export** button
2. Choose format (PNG/JPG/WebP)
3. Design saves to **Media Library**
4. Automatically tagged with source: "design"

### Best Practices

1. **Use Templates** - Start with platform-optimized sizes
2. **Consistent Branding** - Use your brand colors and fonts
3. **Keep It Simple** - Less is more in design
4. **Contrast** - Ensure text is readable
5. **Save Often** - Click Save to preserve your work

## 🎬 Video Editor

### Overview

Timeline-based video editor for creating:
- Instagram Reels (9:16)
- YouTube Shorts (9:16)
- TikTok Videos (9:16)
- Promo Videos (16:9)
- Video Ads

### Getting Started

#### Choose a Template

**Video Templates:**
- 🎬 **Instagram Reel** - 30s, 9:16
- ▶️ **YouTube Short** - 60s, 9:16
- 🎵 **TikTok Video** - 60s, 9:16
- 📺 **Promo Video** - 15s, 16:9
- ⭐ **Testimonial** - 30s, 16:9

### Timeline Interface

#### Toolbar (Left Side)

1. **Video Clip** - Add video segments
2. **Image Clip** - Add static images
3. **Text Overlay** - Add text to videos
4. **Audio Track** - Add background music

#### Timeline (Bottom)

**Timeline Structure:**
- **Ruler** - Time markers (seconds)
- **Video Layers** - Multiple video/image/text layers
- **Audio Track** - Dedicated audio layer at bottom
- **Playhead** - Red line showing current time

#### Playback Controls

- ⏮️ **Skip to Start** - Jump to beginning
- ⏸️ **Play/Pause** - Control playback
- ⏭️ **Skip to End** - Jump to end

### Working with Clips

#### Adding Clips

1. Click tool in left toolbar (Video, Image, Text, Audio)
2. Clip appears at current playhead position
3. Default duration: 3 seconds (10s for audio)

#### Editing Clips

**Select a clip** → Properties appear in right panel

**Clip Properties:**
- Name
- Start time (seconds)
- Duration (seconds)
- Layer position

**Type-Specific Properties:**

**Text Clips:**
- Text content (multi-line)
- Font size
- Color
- Font family

**Video/Audio Clips:**
- Volume (0-100%)
- Speed (coming soon)

**Transition:**
- None
- Fade
- Dissolve
- Wipe
- Slide

#### Timeline Operations

**Split Clip:**
1. Move playhead to split point
2. Select clip
3. Click **Split** button
4. Clip divides into two parts

**Duplicate Clip:**
1. Select clip
2. Click **Copy** button
3. Duplicate appears after original

**Delete Clip:**
1. Select clip
2. Click **Delete** button

### Rendering Videos

#### Render Settings

**Format:**
- MP4 (most compatible)
- WebM (smaller file size)
- MOV (Apple devices)

**Quality:**
- Low - Faster render, larger pixels
- Medium - Balanced
- High - Best quality, slower render

**Resolution:**
- 720p (HD) - Fast, good for social
- 1080p (Full HD) - Standard
- 4K (Ultra HD) - Premium quality

**Estimated Render Time:**
- Formula: ~5 seconds of processing per 1 second of video
- 30s video ≈ 6 minutes render time
- Depends on quality settings

#### Render Process

1. Click **Render** button
2. Configure settings
3. Click **Start Render**
4. Job goes to render queue
5. Progress tracked in real-time
6. Completed video saved to Media Library

### Best Practices

1. **Keep it Short** - Attention spans are limited
2. **Add Text Overlays** - Most viewers watch without sound
3. **Use Transitions** - Smooth clip changes
4. **Background Music** - Enhance engagement
5. **Test on Mobile** - Most viewers use phones

### Prompt Engineering Tips

#### Structure of a Good Prompt

```
[Subject] + [Style] + [Setting] + [Lighting] + [Color Palette] + [Extras]
```

**Example:**
```
Subject: "A sleek laptop"
Style: "minimalist photography"
Setting: "on a modern desk, home office"
Lighting: "natural window light, soft shadows"
Colors: "navy blue and silver accents"
Extras: "shallow depth of field, professional quality"

Full Prompt: "A sleek laptop in minimalist photography style, 
on a modern desk in a home office, natural window light with 
soft shadows, navy blue and silver accents, shallow depth of 
field, professional quality"
```

#### Prompt Keywords

**Quality Modifiers:**
- professional, high-quality, sharp focus, detailed
- 4K, 8K, ultra detailed, photorealistic

**Style Keywords:**
- minimalist, modern, vintage, retro, futuristic
- watercolor, oil painting, digital art, 3D render

**Lighting:**
- soft lighting, dramatic lighting, golden hour
- studio lighting, natural light, neon lights

**Composition:**
- centered, rule of thirds, close-up, wide angle
- bird's eye view, low angle, symmetrical

#### Negative Prompts (What to Avoid)

- blurry, low quality, distorted
- watermark, text, signature
- ugly, deformed, bad anatomy

## 📱 Publishing Workflows

### Direct Publishing

#### From Image Designer

1. Complete your design
2. Click **Export**
3. Choose format
4. Design saves to Media Library
5. Navigate to **Social Media Automation**
6. Asset pre-loads in post composer
7. Schedule and publish

**Or use quick action:**
- Click **Publish** icon in designer
- Redirects to Social Media with asset attached

#### From Video Editor

1. Complete your video
2. Click **Render**
3. Configure settings
4. Wait for render completion
5. Rendered video saves to Media Library
6. Navigate to **Social Media Automation**
7. Create campaign with video

### Campaign Creation

#### Multi-Asset Campaigns

1. Generate multiple images in AI Studio
2. Select all variants you like
3. Click **Continue to Publish**
4. Choose **Create Social Campaign**
5. Assets auto-populate campaign
6. Schedule posts across platforms

#### Platform Optimization

**Instagram:**

**Facebook:**
- Best: 1200×630 posts
- Video: Up to 240 minutes

**LinkedIn:**
- Best: 1200×627 posts
- Video: Up to 10 minutes

**Twitter:**
- Best: 1200×675 posts

## 💡 Tips & Tricks

### Speed Up Your Workflow

1. **Use Templates** - Don't start from scratch
2. **Save Favorites** - Bookmark common assets
3. **Batch Create** - Generate multiple at once
4. **Reuse Assets** - Repurpose across platforms
5. **Keyboard Shortcuts** - Learn the basics

### Quality Guidelines

**Images:**
- Minimum 1000px width for social media
- Use high-contrast text for readability
- Export in appropriate format (PNG for logos, JPG for photos)

**Videos:**
- Add captions (85% watch without sound)
- Keep hook in first 3 seconds
- Optimize for vertical mobile viewing
- Test on actual devices

### Troubleshooting

**AI Generation Failed:**
- Prompt may be too vague - add more details
- Try different phrasing
- Check API quota (may have limits)

**Export Not Working:**
- Browser may block downloads - allow in settings
- Clear browser cache
- Try different format

**Video Render Stuck:**
- Check render queue status
- Render may be processing - be patient
- Complex videos take longer
